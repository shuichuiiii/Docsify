# Docsify 文档站点

这是一个基于 [Docsify](https://docsify.js.org/) 的轻量级文档框架，计划部署到 GitHub Pages。

## 编辑文档

- 首页：`README.md`
- 侧边栏：`_sidebar.md`
- 使用指南：`guide.md`
- 常见问题：`faq.md`

直接在 GitHub 网页中打开对应文件并编辑，提交后即可更新仓库内容。

## 发布

仓库已包含 GitHub Actions Pages 部署工作流。首次使用时，请在仓库 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**。随后推送到 `main` 分支即可触发部署。
